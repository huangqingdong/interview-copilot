ASR 与 LLM 是两个独立服务池

在「服务」菜单分别启用、切换或停用语音识别和语言模型。

预设方案（可选，一键套用两侧）

方案只是把两侧一起设好的快捷方式，可以完全不用；之后顶栏单独改任一侧都不会改写方案定义。任一侧选「停用」再保存，即可得到单边方案。

LLM · 大模型服务

只用于生成译文、参考答案与复盘。参考答案的语言跟随提问语种：英文问给英文稿，中文问给中文稿。与上面的 ASR 服务没有绑定关系。

ASR · 语音识别服务

新建服务先选协议：Azure Speech REST / OpenAI 兼容 / 通用 HTTP（任意国内网关，请求与响应格式可配）/ 本地 faster-whisper。表单只显示当前协议用到的字段，换协议不会丢已填内容。密钥填在「新密钥」，会写成 ${...} 占位，可在识别地址、请求头、额外字段里引用，不明文落盘。
