# Interview Copilot

面试练习工具，支持中英文语音转写、中文翻译和基于个人人设及本地资料的参考回答。ASR 和语言模型可独立配置，翻译与回答按需开启。普通 HTTP ASR 按句提交音频，百炼流式 ASR 支持边说边显示转写。

## 1. 安装和启动

需要 Windows 和 Python 3.10 或更新版本。在 PowerShell 下载项目并安装依赖。如果已下载 ZIP，先解压，再在解压后的目录运行最后一行。

```powershell
git clone https://github.com/huangqingdong/interview-copilot.git
cd interview-copilot
python -m pip install -r requirements.txt
```

| 使用方式 | 启动入口 | 界面在哪里 |
| --- | --- | --- |
| 桌面练习和配置 | 双击 `start.bat`，或运行 `python app.py` | 自动打开电脑端工作台，默认地址是 `http://127.0.0.1:8765/` |
| 共享电脑屏幕时使用手机 | 双击 `start-phone-only.vbs` | 电脑只运行后台服务，在同一局域网的手机或另一台设备上打开界面 |

## 2. 配置服务

1. 在顶栏「服务」菜单中选择要用的「语音识别」和「语言模型」。例如，使用百炼整段转写可选 ASR `bailian-qwen-asr`，使用百炼生成翻译或回答可选 LLM `qwen`。
2. 打开「设置 → 服务密钥」，给选中的服务填写「新密钥」，点击「保存密钥」。保存后即可测试。
3. 只做语音转写时，保持「中文翻译」和「参考回答」关闭。只想测试文字翻译和回答时，可以先只配置语言模型。

### 不用录音，先试一次

回到「面试」，打开「中文翻译」和「参考回答」，展开「手动输入」。输入 `Tell me about a project you delivered.`，选择「英文提问」，点「提交」。正常情况下，工作台会显示原文、中文译文和英文回答。中文提问开启「参考回答」后会生成中文回答。正式开始新会话前，可以先导出或结束这轮测试。

### 启用百炼流式转写

1. 在「设置 → 模型管理」点击 ASR `bailian-qwen-realtime`。如当前是完整视图，先切回「简洁视图」。
2. 保留模型名 `qwen3-asr-flash-realtime`，填写所属地域的业务空间 WebSocket 地址。北京地域示例为 `wss://<WorkspaceId>.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime`。填入实际的 Workspace ID，应用会按模型名自动添加查询参数。[百炼 WebSocket 接入文档](https://help.aliyun.com/zh/model-studio/qwen-asr-realtime-interaction-process)
3. 如已配置同地域的百炼整段 ASR 密钥，可以留空沿用预设的引用，也可为流式 ASR 单独填写密钥。点击「保存模型」，再在「服务 → 语音识别」选择 `bailian-qwen-realtime`。

流式模式边说边显示临时转写，句子确认后才根据开关生成译文或回答。其它支持的 ASR 协议和自定义 LLM 服务也可在「设置 → 模型管理」添加。请求头、请求体和响应路径等高级参数在「高级设置」中编辑。

## 3. 开始一次桌面练习

1. 在「本场设置」选择「练习 · 保存记录」，先用「自动识别中英文」和默认的 `500 ms` 静音断句。讲话时如果经常在句中停顿，可以提高到 `700 ms`。
2. 在「音源」选择「麦克风」或「屏幕共享音频」，点「开始面试」。用麦克风时允许浏览器访问设备。采集网页播放声音时，在浏览器弹窗中选实际播放声音的标签页并勾选「共享标签页音频」。采集桌面应用时，按浏览器弹窗选择支持共享声音的窗口或系统音频。
3. 按需打开「中文翻译」和「参考回答」。首次测试可以先关闭这两个开关，只确认转写能工作。
4. 点击「结束面试」，等页面显示处理完成。若要导出记录，在下一场开始前选择「记录操作 → 导出 Markdown」。

## 4. 在屏幕共享时用手机

1. 如正在电脑上运行桌面版，先点「结束面试」保存记录，再通过「设置 → 高级设置 → 退出服务」退出，也可在启动终端按 `Ctrl+C`。关闭电脑上已经打开的工具页面。
2. 双击 `start-phone-only.vbs`。电脑上不会弹窗。到项目的 `config/access.txt` 复制「手机（推荐）」的完整链接，在同一局域网的手机或另一台设备上打开。
3. 在手机「本场设置 → 音源」选择「电脑播放声音」，点击「开始面试」。电脑后台采集 Windows 默认播放设备的声音，手机显示转写和回答。请确认会议应用的音频输出与 Windows 默认播放设备一致。要收电脑麦克风的声音时，可改为「电脑麦克风」。
4. 用完在手机点「结束面试」，等最后一轮处理完成，再点「设置 → 高级设置 → 退出服务」。手机页面不可用时，可在电脑上双击 `stop-hidden.vbs` 停止后台。

共享模式会拒绝从采集电脑本机打开工具页面。手机链接含访问令牌，持有完整链接可查看和操作会话。请在可信局域网使用。

## 5. 人设、资料和记录

- 在「设置」点击「编辑人设 / 资料库」，然后在「人设」页填写真实经历、表达风格和限制，点「保存人设」。自带人设是虚构示例，适合试用。
- 在「资料库」拖入文件或点「选择文件」。支持 `.md`、`.txt`、`.json`、`.csv`、`.docx`，单个文件最多 6 MB。
- 「练习 · 保存记录」在结束时把非空会话保存到 `runtime/sessions/`。「实战 · 不落盘」在结束时保留内存记录。两种模式都可以手动导出 Markdown。
- 结束后选「记录操作 → 生成复盘」，这一步需要可用的语言模型。「清空记录」会删除当前会话里的记录，使用前可先导出。

## 常见问题

| 现象 | 操作方法 |
| --- | --- |
| 双击后电脑没有弹窗，或者本机页面被拒绝 | 检查启动的是 `start.bat` 还是 `start-phone-only.vbs`。手机模式没有电脑窗口，应在另一台设备访问。 |
| 无法监听 `8765`，或提示 `WinError 10013` / `10048` | 检查已有的桌面版或手机后台。先结束并保存会话，再退出正在运行的服务，然后启动所需模式。 |
| 手机连不上 | 确认手机与电脑在同一局域网，使用最近一次启动生成的完整链接。如果 Windows 防火墙拦截，检查该应用是否允许在当前可信网络上通信。 |
| 点「开始面试」后没有声音或转写 | 先用「麦克风」做一轮短测试，再检查浏览器音频权限、所选标签页以及是否勾选共享音频。手机模式还要检查电脑默认播放设备。 |
| 页面能打开，ASR 或 LLM 却未就绪 | 在「服务」确认选中了正确的服务，在「设置」检查密钥、模型名和服务地址。如果请求返回 `401` 或 `403`，还要核对密钥的地域以及模型权限。 |
| 只有原文，没有译文或回答 | 检查「中文翻译」和「参考回答」是否打开，以及 LLM 是否可用。译文功能用于把英文提问译成中文。 |

## 本地文件与服务请求

- 页面填写的 API Key 保存在本地 `config/.env`，`config/providers.json` 只保存环境变量引用。也可复制 `config/.env.example`，再按需在本机填写。
- 自定义人设保存在 `config/persona.json`，上传资料保存到 `kb/`。密钥、个人资料、会话记录和运行日志已排除在 Git 之外。
- 音频会发给所选 ASR 服务；启用翻译、回答或复盘时，相应文本和配置所需的上下文会发给所选语言模型。请按所在场景的规则和授权使用录音与 AI 辅助。
