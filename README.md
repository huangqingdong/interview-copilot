# Interview Copilot

面试练习工具，支持中英文语音转写、中文翻译和基于个人人设及本地资料的参考回答。ASR 和语言模型可独立配置，翻译与回答按需开启。普通 HTTP ASR 按句提交音频，百炼流式 ASR 支持边说边显示转写。

## 在 Windows 上运行

需要 Python 3.10 或更新版本。进入项目目录安装依赖。

```powershell
python -m pip install -r requirements.txt
```

1. 双击 `start.bat` 打开桌面工作台，或运行 `python app.py`。
2. 在「服务」菜单分别选择语音识别服务和语言模型，在「设置」中填写对应的「新密钥」。只做转写时可关闭翻译和回答。
3. 在「本场设置」选择音源、提问语种和静音断句时间，然后点击「开始面试」。

不用音频时，可展开「手动输入」测试翻译和回答。ASR 服务地址、模型名和协议可在「设置 → 模型管理」编辑。配置百炼流式 ASR 时，选择 `bailian-qwen-realtime`，填写百炼控制台提供的同地域业务空间 WebSocket 地址和密钥，再启用该 ASR。

## 手机查看

屏幕共享前，关闭本机的工具页面和桌面服务，再双击 `start-phone-only.vbs`。用同一局域网的手机或另一台设备打开 `config/access.txt` 中的推荐链接。手机页面的「电脑播放声音」采集 Windows 默认播放设备的音频。完成后先结束面试，再退出后台服务。

桌面模式默认监听 `127.0.0.1:8765`。手机模式允许局域网访问并使用访问令牌，持有完整链接可查看和操作会话。请在可信网络使用。

## 本地文件与服务请求

- 页面填写的 API Key 保存在本地 `config/.env`，`config/providers.json` 只保存环境变量引用。也可复制 `config/.env.example`，再按需在本机填写。
- 人设默认使用虚构示例。自定义人设保存在 `config/persona.json`，资料放在 `kb/`。结束练习会话时可写入 `runtime/sessions/`，实战模式只保留内存记录。以上个人文件已排除在 Git 之外。
- 音频会发给所选 ASR 服务；启用翻译、回答或复盘时，相应文本和配置所需的上下文会发给所选语言模型。请按所在场景的规则和授权使用录音与 AI 辅助。

## 自检与许可证

```powershell
python selftest.py
```

自检用本地测试数据和模拟服务，不需要真实 API Key。
